¿Cómo enviar la cancelación?
1. Llena los datos del extractor, cliente, sucursal y motivo de cancelación.
2. Presiona Generar código.
3. Revisa el código generado.
4. Presiona Mandar correo.
5. Se abrirá el correo dirigido a devlogic.services@gmail.com con todos los datos de la cancelación ya preparados. Solo confirma el envío desde tu aplicación de correo.

Mandar correo
El botón Mandar correo abrirá tu aplicación de correo con el destinatario devlogic.services@gmail.com. El mensaje incluirá automáticamente el código, equipo, sucursal, cliente, fecha, monto y motivo de cancelación. Solo revisa la información y confirma el envío.
